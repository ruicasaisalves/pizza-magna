# Old models

Kept in case we go back to them. Nothing here is loaded by the game.

- `sprites.js`: the first room art, drawn in code on a 16 px grid (floor, walls, furniture, ovens, characters coloured by customer group).
- `room-16px.js`: the room drawing that used it (`drawChar()` and `drawRoom()` from `index.html`), with notes on how to bring it back.
- `room-first-people.js`: the 32 px room atlas as it was with the first people (21 customers, waiter and cook, dithered shading, a two-step walk), and `first-people.png`, a picture of them (on foot from the front, side and back, seated, and the staff).

  To go back to the first people:
  1. either copy `old/room-first-people.js` over `assets/room.js` (restore its first line, `/* Generated by tools/gen_room.py. Do not edit by hand. */`), which also brings back the room art of that day; or, better, in `tools/gen_room.py` (`sprites()`) put back the loop that uses `person()`, `walker()` and `standing()`, which are still there, instead of `pilot_people`, and run it;
  2. in `index.html`, the walking frame goes back to two steps: `` `w${p.rlook||0}_${p.dir}_${p.walking?Math.floor(p.ph)%2:0}` `` (today it plays frames 1, 0, 2, 0).

The game's room now uses the 32 px atlas `assets/room.js` (made by `tools/gen_room.py`).
