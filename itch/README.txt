PIZZA MAGNA - a pizzeria tycoon in 90s pixel art
=================================================

HOW TO PLAY
Just open index.html in your web browser (double-click it).
There is nothing to install, and it plays offline.

Keep all the files together: index.html needs the assets folder
and music.js next to it.

YOUR SAVE
The game saves by itself in the browser that opens it.
To move a game to another browser or computer, use
Options > Download save, then Options > Import save.

The version number is at the bottom of Options: please mention it
when you report a bug.
