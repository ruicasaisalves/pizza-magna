# Fonts

Local copies of the game's fonts, so it looks the same offline (opened straight from disk). They are the
latin and latin-ext `woff2` files that Google Fonts serves, declared with `@font-face` at the top of `index.html`.

| Files | Font | Author | Licence |
|---|---|---|---|
| `pixelify-*.woff2` | Pixelify Sans (variable, weights 400–700) | Stefie Justprince | SIL Open Font License 1.1 |
| `silkscreen-*.woff2`, `silkscreen-bold-*.woff2` | Silkscreen | Jason Kottke | SIL Open Font License 1.1 |
| `vt323-*.woff2` | VT323 | Peter Hull | SIL Open Font License 1.1 |

The ten digits in `../digits.woff2` (`'PM Digits'`) are cut from VT323.
